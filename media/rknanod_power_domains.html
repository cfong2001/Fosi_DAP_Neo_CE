RKNanoD power domains, and where the Neo's firmware lives

Domain contents from the TRM (Table 5-1, Table 12-1). Grey notes are CE's own findings about the Neo.

VD_PMU
PD_PMU stays on in sleep
  • PMU, GRF
  • GPIO2 : Bluetooth power 2.7, Bluetooth UART 2.16/2.17, DAC reset 2.1, DAC mute 2.8
VD_LOGIC
PD_LOGIC
  • System core (inferred): UI, library, playback control
  • SYSRAM0 320 KB 0x03000000 : data, SAVEINFO at 0x030232A0
  • SYSRAM1 256 KB 0x03050000 : module 0 resident, overlays at 0x0307xxxx
  • CRU, I2C, I2S, UARTs, SAR-ADC, timers
PD_HIGH software power-down only
  • Core 1 : decoder modules 71 to 80
  • HIGHRAM0 128 KB 0x01000000 : decoder code (core 1 likely also sees it at 0x0)
  • HIGHRAM1 256 KB 0x01020000 : decoder data
  • HIFIACC : FLAC/ALAC/APE filters, FFT; stock FLAC uses it
Off switch: PMU_PWRDN_CON (+0x0C) bit 1. Whether stock uses it when paused is open.
